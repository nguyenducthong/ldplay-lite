LDPlayer Lite Manager - Bản portable
====================================

1. Chép LDPlayerLiteManager.exe sang máy Windows 64-bit.
2. Máy đích không cần cài Python.
3. Cài LDPlayer 9 trước, sau đó chạy LDPlayerLiteManager.exe.
4. Nếu Manager chưa tìm thấy LDPlayer, mở Cài đặt và chọn:
   - ldconsole.exe
   - adb.exe
5. Để quản lý ứng dụng Android, hãy khởi động instance và làm mới ADB trước.

Cấu hình, backup, log và ảnh chụp được lưu riêng trên từng máy tại:
%APPDATA%\LDPlayerLiteManager

Mã SHA-256 được cung cấp cùng thông tin phát hành để kiểm tra file sau khi sao chép.
